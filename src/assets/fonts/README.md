# Fuentes CosechApp

Fuentes **locales** (no CDN) para que la app funcione sin conexión. Se cargan desde `src/theme/variables.css`.

| Fuente | Peso | Archivo | Uso |
|--------|------|---------|-----|
| Zilla Slab | Regular (400) | `ZillaSlab-Regular.woff2` | Títulos (display) |
| Zilla Slab | Bold (700) | `ZillaSlab-Bold.woff2` | Títulos (display) |
| Inter | Regular (400) | `Inter-Regular.woff2` | Cuerpo, números, UI |
| Inter | Bold (700) | `Inter-Bold.woff2` | Cuerpo, números, UI |

Origen: paquetes `@fontsource/inter` y `@fontsource/zilla-slab` v5.3.0, subconjunto *latin* (incluye tildes y ñ).
